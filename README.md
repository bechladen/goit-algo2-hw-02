## Домашнє завдання

Проєкт містить 2 незалежні задачі (окремими файлами).

### Завдання 1: мінімум і максимум (divide and conquer)

- **Файл**: `task_1.py`
- **Функція**: `find_min_max(numbers) -> (мінімум, максимум)`
- **Підхід**: рекурсія, метод «розділяй і володарюй»
- **Складність**: \(O(n)\)

Запуск прикладів:

```bash
python task_1.py
```

### Завдання 2: оптимізація черги 3D-принтера (жадібний алгоритм)

- **Файл**: `task_2.py`
- **Функція**: `optimize_printing(print_jobs, constraints) -> {"print_order": [...], "total_time": ...}`
- **Підхід**:
  - спочатку за пріоритетом (1 → 2 → 3)
  - далі жадібне групування у партії без перевищення `max_volume` і `max_items`
  - час партії = максимум `print_time` у партії

Запуск тестів з умови:

```bash
python task_2.py
```
